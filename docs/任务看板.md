# AutoIt v3 内置函数实现任务看板

> **用途**：把 AutoIt v3 官方函数表中尚未落地的内置函数整理成可执行的任务清单，
> 并按「通用」与「需要仿真」分开，供 `autoitv3-runtime` / `autoitv3-platform` 逐项实现。
>
> **依据**：AutoIt v3 官方函数表（`functions.htm`，共 **403** 个内置函数）
> × 本仓库现状（`crates/autoitv3-runtime/src/builtins.rs`、
> `crates/autoitv3-platform/src/{common,linux,windows}/`、`.../winemu/`）
> × 真实脚本对内置函数的使用情况。
>
> **配套文件**：逐函数机器可读状态表见 `docs/函数实现状态.tsv`
> （由源码的 match 分支整理生成）。

全部已落地并有回归测试；逐项状态见 `docs/函数实现状态.tsv`。

| ---- | ---- | ---- |

| 文件 / 目录（9） | `common/` | `FileChangeDir` `FileGetPos` `FileSetPos` `FileSetEnd` `FileGetEncoding` `FileReadToArray` `FileFindFirstFile` `FileFindNextFile` `FileSetTime` |
| INI（7） | `common/` | `IniRead` `IniWrite` `IniDelete` `IniReadSection` `IniReadSectionNames` `IniRenameSection` `IniWriteSection` |
| 进程 / 执行 / 标准 IO（10） | `common/proc.rs` | `Run` `RunWait` `ProcessWait` `ProcessWaitClose` `ProcessGetStats` `ProcessSetPriority` `StdoutRead` `StderrRead` `StdinWrite` `StdioClose` |
| 网络（25） | `common/net.rs` | `InetGet` `InetGetInfo` `InetGetSize` `InetRead` `InetClose` `FtpSetProxy` `HttpSetProxy` `HttpSetUserAgent` `Ping` `TCPStartup` `TCPShutdown` `TCPConnect` `TCPListen` `TCPAccept` `TCPRecv` `TCPSend` `TCPCloseSocket` `TCPNameToIP` `UDPStartup` `UDPShutdown` `UDPOpen` `UDPBind` `UDPRecv` `UDPSend` `UDPCloseSocket` |

**已记录的近似**（与 README「不静默编造值」一致）：

- `FileGetEncoding` 返回 AutoIt 的 `32/64/128/256/512`，纯 ASCII 返回 `0`
- `FileFindNextFile` 的 `flag = 1`（属性字符串写入 `@extended`）无法表达，退化为 `0`
- `FileSetTime` 的创建时间（`type = 1`）在宿主上不可设置，返回失败
- `StringIsLower`/`Upper` 要求至少含一个字母，且所有字母大小写一致
- `MapAppend` 取"下一个未占用的正整数键"；Map 键在本运行时是字符串，故整数键与
  同数字的字符串键无法区分
- `Run` 的 `show_flag` 在非 Windows 上忽略；`$STDERR_MERGED` 用缓冲区拼接模拟
- `ProcessSetPriority` 只报告成功，不真正改 nice；`ProcessWait`/`WaitClose` 阻塞等待，
  确定性分析配置下立即返回
- `Inet*` 只支持明文 `http://`（无 TLS），`https://` 立即失败；`TCPAccept` 非阻塞
- 网络/进程副作用全部受 `ExecutionProfile` 门控，`deterministic()` 下拒绝执行

## 四、列 B：✅ 已完成 · 需要仿真 · 可落地（28）

全部在 `winemu/` 落地并有回归测试：

| 分组 | 落地位置 | 函数 |
| ---- | ---- | ---- |
| Windows 文件 / PE（7） | `winemu/verinfo.rs`、`winemu/shortcut.rs`、`winemu/mod.rs` | `FileGetVersion` `FileCreateShortcut` `FileGetShortcut` `FileCreateNTFSLink` `FileRecycle` `FileRecycleEmpty` `FileInstall` |
| 回调（4） | `winemu/mod.rs` | `DllCallAddress` `DllCallbackRegister` `DllCallbackGetPtr` `DllCallbackFree` |
| COM（6） | `winemu/mod.rs` | `ObjCreate` `ObjCreateInterface` `ObjEvent` `ObjGet` `ObjName` `IsObj` |
| 系统信息 / 驱动器（6） | `winemu/mod.rs` | `MemGetStats` `IsAdmin` `DriveMapAdd` `DriveMapDel` `DriveMapGet` `DriveSetLabel` |
| 执行 / Shell（5） | `winemu/shell.rs` + `winemu/mod.rs` | `ShellExecute` `ShellExecuteWait` `RunAs` `RunAsWait` `Shutdown` |

**已记录的近似**（与「不静默编造值」一致）：

- `FileGetVersion` 解析 PE 的 `RT_VERSION`（VS_FIXEDFILEINFO + StringFileInfo）；
  没有版本资源时按 AutoIt 语义返回 `"0.0.0.0"` + `@error = 1`
- `FileGetShortcut` 只解析 Shell Link 的 `LinkInfo` + `StringData`；写入不含
  `LinkTargetIDList`，路径按 ANSI 存储
- `FileCreateNTFSLink` 的 junction 用宿主符号链接模拟；宿主不支持时返回失败
- `FileInstall` 先按磁盘文件复制，源不在磁盘时回退到已加载模块的 `RT_RCDATA` 资源
- COM 无运行时：`Obj*` 返回 `0`/`""` 并置 `@error = 1`，`IsObj` 恒为 `0`（不编造对象）
- `DllCallAddress` 无 PE 加载器：地址不可解析，返回 `0` + `@error = 1`
- `DllCallback*` 只分配/登记指针，不会真的被原生代码回调
- `MemGetStats` 返回固定的 8 GiB 仿真机器内存表（可复现）
- `RunAs`/`RunAsWait` 接受凭据但不切换用户；`ShellExecute` 不模拟文件关联
- `Shutdown` 只记录请求并返回成功，绝不真正关机
- 写文件、驱动器映射、启动进程受 `ExecutionProfile` 门控，`deterministic()` 下拒绝

## 五、列 C：✅ 无头 + ✅ 离屏渲染 · GUI / 窗口 / 输入（165）

165 项的**无头语义**全部落地在 `winemu/gui/`：控件是内存对象、句柄是整数，
`GUIGetMsg` 无事件时返回 `0`，`GUICtrlRead` 返回脚本自己设进去的数据，
`GUICtrlSendMsg` 对 `$EM_*`/`$LVM_*` 给出文档化默认值（未知消息置 `@error = 1`）。

分析场景靠脚本化事件收口：`with_gui_events([...])` 预置 `Close`/`Control(id)` 等，
`with_gui_auto_close(n)` 让第 n 次 `GUIGetMsg` 返回 `$GUI_EVENT_CLOSE`，
`with_gui_answers([...])` 给 `InputBox`/`File*Dialog` 提供答案（无答案即按取消处理）。

**渲染（M2c，已完成）**：控件模型与 `GuiBackend` 接缝抽到零依赖 crate `autoitv3-gui`；
`autoitv3-gui-egui`（feature `egui`，默认关）用 egui 布局 + 自带 CPU 光栅器产出 RGBA，
并提供 `snapshot()` / `screenshot()` / `with_screenshot()`。平台侧 `gui-egui` feature
提供 `with_egui_backend()` 与 `gui_snapshot()`。**仍是离屏、无交互**。

## 八、验收标准

1. **语义可判定**：新增函数要么给出真实结果，要么按 AutoIt 语义失败并置 `@error`；
   不允许"静默编造值"（与 README「不静默编造值」一致）。
2. **受执行配置约束**：写文件/注册表/网络/启动进程等副作用必须走
   `ExecutionProfile`，`deterministic()` 下拒绝。
3. **归层正确**：平台无关与宿主进程/网络进 `builtins.rs`/`common/`
   （`proc.rs`/`net.rs`），Windows 语义进 `winemu/`；
   `Platform` trait 之外不新增平台耦合。
4. **有回归测试**：每个函数一个用例，覆盖正常路径、边界（空值/不存在/权限）与 `@error` 行为。
5. **可复现**：涉及随机/时间的函数在 `deterministic()` 下结果稳定。
